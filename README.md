# Guilherme Pontes

> Estudante de Sistemas de Informação (IFAL) | Pesquisa aplicada em Ciência de Dados (PIBIC/CNPq – INPE) | Back-end

Atualmente dividido entre **desenvolvimento back-end** (Python, Node.js, Java) e **pesquisa aplicada de dados em saúde pública**, como bolsista de Iniciação Científica no INPE.

### 🔬 Pesquisa

Bolsista PIBIC/CNPq no INPE, desenvolvendo pipeline de dados do DATASUS e dashboard interativo (Streamlit/Plotly) para análise de tendências epidemiológicas, com inserção dos resultados na plataforma AdaptaBrasil (MCTI).
